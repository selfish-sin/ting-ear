# AI 阅读体验与模型设置优化

## Goal

让 AI 阅读模式保持轻量、模型设置开箱即用，并让书籍知识库状态反映 nmem 的真实可检索状态。

## Requirements

- AI 阅读模式不显示完整底部播放栏，只显示右下角常驻的小胶囊播放器。
- 小胶囊在普通和沉浸模式下都可见，提供上一句、播放/暂停、下一句。
- 听书模式继续使用现有完整播放栏。
- 沉浸模式入口只放在窗口顶栏，正文区不出现重复入口。
- 删除防剧透设置、提示词、检索过滤与相关 UI 文案。
- AI 普通设置提供服务地址、API Key、获取/刷新模型、模型选择、连接测试、备用模型和任务分配。
- 提示词、路由规则、超时和手动模型 ID 兜底放入高级设置。
- nmem 同步必须区分未同步、提交中、索引中、可检索和失败；本地记录不能单独作为成功依据。
- 导入书籍后可自动同步；启用自动同步后应补同步现有书籍；支持手动重新同步。
- 模糊提问的检索查询应组合用户问题、选中文本、当前句和章节标题。

## Constraints

- 沿用现有 React、Zustand、Electron IPC、Tailwind 与 lucide-react。
- 不新增大型 UI 或 AI SDK。
- 模型发现采用 OpenAI-compatible `GET /models`，失败时允许手动填写模型 ID。
- 保留用户当前未提交改动，不进行无关重构。
- 测试只覆盖本次改动的关键行为。

## Acceptance Criteria

- [ ] AI 阅读进入、播放、暂停或沉浸时均不出现完整底栏，小胶囊始终位于右下角。
- [ ] 顶栏是唯一的沉浸模式入口。
- [ ] 设置页可获取模型、选择模型、测试连接，并清晰显示结果。
- [ ] 防剧透字段和行为从设置、提示构建和检索过滤中移除，旧设置可被兼容读取。
- [ ] nmem 本地状态与服务端无数据不一致时会重新同步，不再显示虚假的完成状态。
- [ ] 导入书籍最终能够进入可检索状态，失败时显示可重试错误。
- [ ] AI 检索能使用问题、选文、当前句和章节标题构造查询。
- [ ] 关键测试、类型检查和构建通过。
