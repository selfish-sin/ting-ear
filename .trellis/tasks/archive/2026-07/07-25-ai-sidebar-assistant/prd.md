# AI 阅读重构 - PRD

## 需求

将听伴从"TTS 朗读工具"升级为"AI 阅读伴侣"。主页面为 AI 阅读模式（结构化卡片 + AI 对话），TTS 朗读降为附属功能。以 Nowledge Mem 为知识层，OpenAI 兼容 API 为推理引擎。所有配置从前端设置页管理，零硬编码。

## 具体例子

- 给「用户导入一本 MD 格式书籍（含 # 标题、正文、脚注）」，期望「AI 阅读页面显示结构化卡片：标题大字号、正文正常、脚注灰显折叠。大纲栏可点击跳转」
- 给「用户在 AI 阅读页面输入"笛卡尔的怀疑方法有几层？"」，期望「检索卡片显示"找到3条"，AI 流式回答，[1][2] 标注可点击→弹出原文→[定位]跳到对应卡片」
- 给「用户选中卡片中"方法论怀疑"四个字，点浮动条[引用]，再选另一段，点[问AI]」，期望「输入框上方两张引用卡片，输入问题后发送，AI 基于两段引用回答」
- 给「用户读到第5章，防剧透开启，问"后面发生了什么？"」，期望「AI 拒绝透露后续内容」
- 给「用户切换到听书模式」，期望「界面变为现有句子列表，TTS 从当前位置继续播放，脚注句被跳过」
- 给「用户在 AI 阅读页面点击某张卡片的 [▶] 按钮」，期望「TTS 从该段第一句开始朗读，当前句高亮，读完该段停止」
- 给「nmem 未启动」，期望「AI 对话面板顶部黄色横幅"知识库未连接"，仍可直接对话」

## 验收标准

### 结构与导入
- [x] MD 导入保留标题层级（#/##/###）、段落、脚注、引用块、代码块结构
- [x] EPUB 导入保留 HTML 结构（h1-h6、p、footnote、blockquote）
- [x] PDF 导入生成伪结构（基于 detectHeadingBoundaries）
- [x] 旧书（无 structure）在 AI 阅读页面用伪结构 fallback 显示
- [x] 导入时可选自动 ingest 到 nmem（设置页开关）

### AI 阅读页面
- [x] 打开书默认进入 AI 阅读模式（三栏：大纲 + 卡片 + AI 对话）
- [x] 大纲栏可折叠，点击章节→卡片区滚动到对应位置
- [x] 卡片按 block type 分层渲染（标题/正文/脚注/引用/代码不同样式）
- [x] 脚注卡片默认折叠、灰显
- [x] 当前 TTS 播放句所在卡片高亮，句内文字高亮
- [x] 卡片右上角 [▶] 按钮可朗读本段
- [x] AI 对话面板可折叠/拖拽宽度

### AI 对话
- [x] 流式输出（逐字渲染），Markdown 格式（代码块/列表/粗体）
- [x] 提问后显示检索状态卡片（"正在检索…"→"找到 N 条"）
- [x] [N] 标注渲染为可点击药丸→Popover 显示原文→[定位]跳到对应卡片
- [x] 选中文本→浮动条 [复制] [引用] [问AI]
- [x] 引用卡片可叠加（最多5张），组合后提问
- [x] 防剧透模式（默认开启）：先硬过滤检索结果，再加 prompt 约束
- [x] 问题路由（greeting 跳过检索、selection 以引用为主、chapter 限定当前章）
- [x] AI 回答朗读（独占播放状态机，书籍暂停→朗读→恢复）
- [x] 对话历史持久化（按书分组）
- [x] nmem 断线降级（横幅 + 无 RAG 直聊）
- [x] LLM 错误可操作消息（不静默吞错）
- [x] 流式 IPC 含 requestId + seq，cancel(requestId) 只取消对应请求

### 模式切换与 TTS
- [x] 模式切换（AI 阅读 / 听书），TTS 播放不中断
- [x] 听书模式 = 现有 PlayerView（句子列表 + ControlBar），基本不动
- [x] 听书模式中 ttsSkip 句子（脚注/页码/目录）被跳过
- [x] ControlBar + ProgressBar 在两种模式下都全宽可用
- [x] 沉浸模式下 AI 对话面板隐藏

### 配置
- [x] 设置页可配置：nmem/LLM/检索/对话 四段（Skills 二期加）
- [x] 所有用户可见文案中文
- [x] 无硬编码：端口/URL/模型名/prompt/阈值/路由正则全部从配置读取

## 二期内容（一期完成后）

- Skills 系统（预设问答：总结/解释/翻译/批判 + 设置页 CRUD）
- 思维导图 Skill（markmap SVG，右键节点→问AI）
- 深度控制（概要/标准/详细）
- 语义上下文压缩（>20轮自动压缩，用免费模型）
- PDF→MD 预处理（pymupdf4llm）
- LLM 结构标注（OCR TXT 用免费模型识别结构）
- 字幕窗口联动（右键→问AI）
- 跨书联合检索 UI
- 知识图谱可视化

## 不做项

- 不做本地模型推理（用户明确排除）
- 不做多轮 Agent/Tool Calling（一期单轮 RAG + 直答）
- 不做 Nowledge Mem 自动启动（用户自行管理）
- 不做语音对话（三期）
- 不做 TXT/DOCX 结构识别（极少使用，走伪结构 fallback）

## 影响范围

- 影响现有功能：
  - 书籍导入流程（parser 保留结构 + 可选 ingest）
  - 数据模型（BookData 新增 structure 字段）
  - App.tsx（模式切换）
  - PlayerView（顶栏+模式按钮+ttsSkip 灰显）
  - useTTS（ttsSkip 跳过 + speakRaw，~50行）
  - 设置页（新增 AI 配置区块）
  - preload.ts（新增 AI IPC）
- 不影响：ControlBar / ProgressBar / SentenceRow / SideNav / 字幕窗口 / 浮球 / 书架 / 历史 / TTS 核心引擎

## 风险与回滚

- 风险等级：L（数据模型变更 + 新页面 + 跨模块协调 + 外部依赖）
- 不可逆操作：无（structure 可选，nmem 数据可删）
- 回滚方式：
  - 代码层：git revert（AI 模块独立）
  - 数据层：books.json 中 structure 字段删除即回退；nmem 删 source
  - 配置层：settings.json ai 段整段删除
  - 降级：无 structure 的旧书自动 fallback 伪结构，不崩溃
